# ComfyUI 手机工作台 2.0.0

2026-10-18，组件版本码 6。工作流由手机持有，电脑负责模型与执行。沿用现有工具匣宿主和组件下载方式；仓库交付 DEX、清单、签名，不交付组件 APK。

## 使用

同步组件仓库，更新 ComfyUI。创作页可直接打开本地工作流，不要求先登录。参数与画布编辑同一份文档；画布可平移、缩放、点击节点，节点列表可编辑参数和输入连接。当前文档自动保存，也可保存最多 30 个命名版本。

同步一次电脑目录后，节点类型和模型选项缓存在手机，离线仍能编辑。模型权重不传到手机；重新同步会更新可选项。运行时发送包含当前参数的完整 API 工作流与参考图，电脑再次核验实际节点和模型后提交给 ComfyUI。连接服务仍需运行，公网传输仍受所用隧道和网络影响。

方向跟随系统设置。关闭手机方向锁定后，可从竖屏切换为横屏，横屏采用侧边导航与紧凑工具栏，返回竖屏保留工作流和参数。

电脑连接服务需使用本次更新的 `services/toolcase/workflows.py`。新增 `inputOrder`、`forceInput`、`controlAfterGenerate`、`uiImportSupported` 元数据，兼容旧客户端。重新启动连接服务后，用原口令重新登录；命名工作流、作品和访问口令保留。

## 协议调查

按要求从 [morluto/rea](https://github.com/morluto/rea) 安装了 reverse-engineer-anything skill。其指引明确要求完整源码仓库直接用常规源码工具分析，本次因此没有运行二进制反编译器或 REA 外部提供商。

检查本机 ComfyUI 的 `server.py`、节点接口、执行入口和现有连接服务，确认 `/object_info` 返回节点与模型选项，`POST /prompt` 接受完整 API 图。工作流不需要预先在电脑上保存。实现不改动 ComfyUI 源码，也不需要把整个桌面网页或 Python 引擎放入手机。

## 兼容边界

- API JSON 保留未知节点及其参数，并报告阻止运行的问题；不静默删除节点。
- 普通画布 JSON 只有在控件顺序可确定时才转换。遇到未同步目录、绕过、虚拟、动态或不支持的扩展节点，保留整份原始文件供保存和导出，可改用受支持的 API JSON。
- 已转换并编辑的工作流导出为 API JSON；不承诺任意桌面画布元数据完整往返。
- 原生画布暂不支持拖动单个节点排版；不运行第三方桌面 JavaScript 扩展。支持的执行节点仍由电脑策略确定，本机此次目录为 61 类。
- 参考图片选择不跨应用重启永久保留；工作流和参数会保留，图生图重开后需重新选择图片。
- 本次没有重新进行 GPU 生图，也未在用户的实体手机上验收。
