# 视频剪辑 3.0.0

在工具匣组件管理中刷新 / 同步仓库，更新“视频剪辑”至 3.0.0。组件版本码 5，接口 2，要求宿主版本码至少 12；建议使用已修复签名传输问题的 0.9.1 或更新版本。

- 重构深色剪辑、导出和进度界面。主界面专注画面与时间轴，高级导出设置默认折叠。
- 支持整文件夹（含子目录）和相册导入、拍摄时间排序、真实帧预览、精确裁剪、分割、旋转、手动排序、撤销 / 重做和草稿自动保存。
- 无损直拼、H.264、H.265 分别显示预估大小。先检查直拼与编码支持情况，用户“确认并开始”才执行，关闭面板不启动。
- 期望体积用于限制目标码率，不把成功合成的超估结果判失败。实际大小超过估值 25% 时，保存前展示差异，让用户接受或返回调整。预估不是大小或画质保证。
- 前台服务、进度通知与任务持久化支持切屏 / 锁屏合成。关闭剪辑页面不会取消任务，主动取消不会在重开后重新启动。
- 系统终止视频进程后保留已确认任务，系统重建服务或再次打开可恢复。恢复从头合成，不是断点续编码；无法保证应用永不被系统或厂商省电终止。

视频素材读取与后台运行仍受 Android 权限、原文件可用性和厂商策略约束。Android 15 的媒体处理前台服务存在后台时限，超时保留任务供回到应用后继续。相册仅能读取已经授权的本地素材。

## 验证

9 项单元测试及 4 个 Android 设备测试用例已通过，最终测试环境为 Android 14 x86_64 模拟器与工具匣 0.10.1。覆盖真实 H.264 / H.265 编码、无损压缩包一致性、文件夹 / 相册导入、触摸拖帧、跨片段解码画面、导出确认、撤销 / 重做、小屏大字体、72 秒任务的切屏 / 进程终止 / 锁屏恢复，以及取消持久化。

未用用户原始 1.3 GB 视频或小米 HyperOS 真机验证长视频画质、性能和后台策略。
