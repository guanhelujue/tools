# 相册助手 1.1.1

发布日期：2026-10-17。组件 ID：`album`，versionCode：4，moduleApi：2，最低宿主 versionCode：21。

## 更新与使用

需要先安装工具匣 **0.12.1 / versionCode 21 或更新兼容宿主**，再在组件管理中同步本仓库，更新「相册助手」。主 APK 单独交付，不存入组件仓库；仅更新组件不能为旧宿主增加悬浮入口或新版统一 AI 设置。

此版本包含 1.1.0 的小米相册悬浮「找图」按钮和半屏搜索界面，并适配 0.12.1 的单模型统一 AI 设置：选择厂商、填写 API 地址与 Key、选择或填写一个模型后保存即可。不再要求预先通过视觉能力验证；所选模型仍须实际支持图片输入与相册要求的结构化输出，调用失败会如实显示错误。

首次开启相册助手时按引导授权悬浮显示及「工具匣 · 小米相册按钮」无障碍服务；打开小米相册后点击「找图」。这是工具匣悬浮入口，不修改小米相册 APK。无障碍服务只检测前台窗口切换，不读取窗口内容、文字、截图或手势。

在半屏的「照片与分析」中选择照片范围并建立本地索引，之后用中文搜索。索引前显示模型来源、处理范围和发送确认；使用云端服务时，缩略图会发送至该提供方，本机代理不代表本地识别。已有索引可复用，搜索不会重新上传整个相册。只读取实际授权且可访问的图片，不包含未下载的云照片。

## 验证与当前限制

0.12.1 / 1.1.1 已完成生产构建、12 项相册检索/结构校验单元测试，以及 17 个不同的模拟器设备测试。设备测试覆盖统一设置、地址处理、网关错误和取消、跨进程凭据边界、真实签名相册组件的 Binder 图片请求链路。上游使用本机模拟 API 和合成图片；交付 APK 不包含测试 Service。

1.1.0 已通过模拟器中的悬浮按钮显隐、半屏尺寸、横竖屏、键盘、面板外关闭及权限撤回等交互验证；1.1.1 保留该交互实现。模拟器相册窗口是测试占位应用，**尚未完成小米 HyperOS 真机兼容验收**。

**尚未完成真实模型识图质量和真实模型端到端验收**：没有可用服务商凭据，未上传用户真实照片。模拟 API 测试不能代表中文照片搜索效果，实际可用性取决于所选服务的图片能力、结构化输出和识别质量。

当前精简半屏入口提供搜索、授权与分析；原 1.0.0 的虚拟相册及整理建议代码保留，尚未迁入半屏入口。首次开启不会自动上传照片，不自动搬动或删除原图。时间与来源等确定信息使用媒体元数据，不将模型猜测当作事实。内置 EasyCLIProxy 另需兼容版本的 CLI 组件；本次未更新 CLI，外部 API 无此依赖。
