# 相册助手 1.2.0：悬浮球、归档与本地找图

配套宿主：工具匣 0.12.2 / versionCode 22；album 1.2.0 / versionCode 6 / moduleApi 2。

## 使用流程

先安装新版主应用，再导入或在线更新相册组件。旧 0.12.1 没有新的普通悬浮服务，不能只更新组件。

1. 打开相册助手，允许工具匣“显示在其他应用上层”，再点“开启悬浮球”。无需系统无障碍菜单，也无需开启旧的“工具匣 · 小米相册按钮”服务。
2. 点击悬浮球打开半屏；拖动后吸附最近屏幕边缘，记住位置；长按或点通知中的“关闭悬浮球”即可结束。也可直接打开归档与找图，不开球。
3. “照片归档”：选择图片或媒体库相册，确认模型来源和本批范围后处理。描述、分类和检索索引落在手机；原图不移动、不删除。
4. “描述找图”：查询本地检索库，显示可能匹配的照片及依据；可预览、查看原图、分享、加入手动相册，或将描述及时间等条件保存为智能相册。
5. “选择更多照片”向当前选择器范围追加；设置里的“重新选择照片”替换范围，失去范围或读取权限的图片会从索引移除。

半屏有“照片归档 / 描述找图”两个固定入口；内容可滚动，顶部箭头可展开至约 90% 高度。归档页恢复自动分类、虚拟相册、重复/相似/画质建议入口。AI 未配置时说明原因，已有索引仍可搜索。未完成项和不确定请求可暂停、取消、明确重试；Wi-Fi、充电和每批 1–50 张选项保留。

悬浮球使用用户主动启动的 specialUse 前台服务和常驻通知，不检测前台应用，不获取屏幕或无障碍内容。锁屏隐藏；授权撤回或组件不可用时关闭。系统设置等敏感窗口可能由 Android 隐藏第三方悬浮窗。进程被系统结束后需主动重开，不承诺不可被杀死；没有后台偷开或开机自动启动。

## 检索库与向量边界

此前图片理解结果已持久化，本轮搜索也不上传照片、不调用模型。新增 SQLite 倒排表及本地稀疏词项向量：

- 分词规则 `zh-character-bigram-l2-v1`：中文及其他字母/数字单字与二元组；词频开平方后 L2 归一化。
- 倒排表通过词项索引召回；词项向量点积辅助排序。日期、时段、来源、GPS、多条件 AND 与排除条件仍由确定规则复核。
- SQLite schema 2 → 3：旧描述在后台本地补建词项索引，无需重新解码或上传照片。索引条目同时保存分析身份和检索规则版本。
- 描述变化、模型失效、图片删除及授权范围收缩会清除对应词项；恢复后可从已保存描述补建。单次查询最多 256 个词项，参数化查询，结果按页加载。
- 这是可离线运行的**词项向量**，不是神经网络语义 Embeddings。它保留现有中文同义词规则，仍可能漏掉表达差异较大的描述。“或”的混合条件、含糊旅行时间与缺失 GPS 不猜测。
- 公共网关保留 Embeddings 请求契约，但当前没有经实测的向量来源，内置 CLI 也没有已实现的向量路由。本轮不引入向量模型、不增加私有 API 配置、不把稀疏词项检索宣传为多模态语义向量搜索。

图像描述缓存仍包含缩略图内容散列、统一模型身份和分析规则；已归档图片只在变化或用户明确重建时重新处理。云端识图发送去 EXIF 缩略图，本机代理可能转发到云端，归档前逐批确认。

## 验证范围

验证使用独立 Android 14 模拟器和测试图片，没有操作用户真机、相册或凭据。UI 图片描述为测试夹具，不代表模型识别结果；生产代码没有这些替身结果。真实厂商视觉推理及 HyperOS 真机交互仍待真实配置和设备验证。最终测试数量、产物哈希和截图见交付目录 verification。
