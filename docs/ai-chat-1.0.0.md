# AI 对话 1.0.0

发布于 2026-10-23。组件版本代码 2，moduleApi 2；最低主应用为 **工具匣 0.14.0 / versionCode 24**。组件采用现有发布者签名，运行在独立的 `:component_chat` 进程。

## 安装

先覆盖安装单独交付的工具匣 0.14.0 APK，再在组件管理同步本仓库，选择“AI 对话”安装。旧宿主缺少入口和多轮消息接口，需要升级后使用。本仓库不包含主 APK。

## 使用

- 在“AI 设置”选择模型来源并获取模型列表。聊天复用主应用的配置，不另存 API Key。
- 输入 `/` 或 `/模型名称片段` 选择当前来源的模型；也可点击顶部模型名称。切换模型保留当前会话。
- 支持多轮连续对话、流式显示、停止、复制、代码块、失败或停止后的手动重试。顶部可新建对话、查看历史和调整设置。
- 系统提示词默认面向通用问答和写作，在会话设置中可编辑或恢复；不会输出内部推理过程。

## 上下文

默认总预算 8K，可选择 4K / 16K，预留 2048 tokens 用于回复。字数是本地估算，需结合实际模型的上下文限制选择。

自动压缩在下一次发送将超预算时触发：先尝试保留最近三轮原文，再按需要进一步压缩较早内容。手动压缩每次处理一批完整轮次。摘要合并旧记忆与新增内容，只作为背景传入模型；摘要有效且成功保存后才推进压缩边界。

本机完整记录保持可读，设置中可查看或清除摘要。压缩有损且会调用当前模型，可能计费；过长的单条消息或轮次会明确提示，不静默截断。失败或停止的回复不进入后续上下文，重试不会重复追加用户消息。

会话、草稿、模型选择和提示词存储于组件私有目录，原子写入；流式回复约每两秒保存一次。中断的回复在重开后标记为未完成。卸载组件会删除本地会话。

## 验证与限制

17 项 JVM 单元测试通过，其中 12 项为新增聊天和协议测试；Android API 34 模拟器 13 项设备测试通过，覆盖签名组件加载、跨进程网关、模型选择、角色顺序、两种协议、多轮回复、重试、手动与自动压缩、取消及会话恢复，同时包含原有网关回归测试。

设备测试使用本机 HTTP 测试服务固定回复，验证 UI、Binder、HTTP 和持久化流程，没有调用用户在线模型。真实模型摘要质量、具体上下文上限及其他厂商真机表现尚未实测。本版无附件、联网工具或完整 Markdown 排版。
