# ComfyUI 2.1.0：调用电脑工作流与大图查看

组件版本码 7，电脑连接服务 0.6.0，2026-10-18。

## 手机使用

1. 在组件管理同步 `guanhelujue/tools`，单独更新 ComfyUI 至 2.1.0。仍按文件下载组件，不安装组件 APK。
2. 电脑打开 ComfyUI，将常用工作流保存到 ComfyUI 的工作流目录。在手机创作页进入「电脑工作流」；原手机编辑页面的工作流菜单也提供「使用电脑工作流」。
3. 点击工作流卡片，从「ComfyUI 已保存」选择文件。提示词、尺寸、模型和节点来自该文件。修改提示词、画面尺寸后点击「运行电脑工作流」。模型及其他参数默认沿用电脑配置，运行不会修改电脑原文件。
4. 「恢复电脑参数」可恢复该工作流最近同步的值。电脑目录约每 30 秒更新；在电脑新保存后稍等，再点「同步电脑目录」。
5. 「手机编辑」仍可使用节点画布和本地草稿，两个入口分别保存当前参数。横竖屏继续跟随系统设置。

完成图片可点击打开全屏查看器，支持双指缩放、双击放大、拖动、＋/−、复位和保存。查看器请求原图文件；加载失败显示重试。为控制手机内存，超过 800 万像素或长边 4096 的图片按比例采样解码，原文件保存不受影响；超过 64 MiB 请保存后查看。视频仍通过保存后播放。

## 电脑服务

本次新增 `desktop_workflows.py` 并更新 `agent.py`、`templates.py`，从本机 ComfyUI `/userdata` 读取已保存工作流；不修改 ComfyUI 核心或用户工作流。配套电脑服务源码位于 [comfy-bridge-0.6.0.zip](../desktop/comfy-bridge-0.6.0.zip)。它包含运行代码、示例方案与启动脚本，不包含模型、用户素材、访问口令或 SSH 私钥。

已有安装：先停止旧连接服务，将包内 `services/`、`scripts/` 合并到原工具匣目录，保留原 `.local-share/` 和 `.venv/`，然后重启连接。服务重启后，手机用原口令重新登录。不要将包覆盖到 ComfyUI 安装目录。

新安装：解压到独立目录，使用 Python 3.11 或更新兼容版本创建虚拟环境，安装 `services/requirements.txt`。运行 `scripts/start-tunnel.ps1 -Python <虚拟环境python.exe的绝对路径>` 设置访问口令；登记生成的 `.local-share/identity.pub` 公钥后启动隧道。默认读取 `http://127.0.0.1:8188` 上的 ComfyUI。免费隧道网址仍可能变化，以启动日志显示的地址为准。

## 兼容范围与验证

- 支持已审核节点组成的 API JSON，以及控件顺序可确定的普通画布 JSON。动态扩展控件、旁路、虚拟节点、缺失模型或超限文件会列入「暂不能运行」并说明原因，不自动替换模型或删除节点。
- 当前电脑读取到 17 个保存文件，其中 7 个可转换并通过节点与参数校验，其他 10 个显示原因。另保留原有 8 套已配置方案。该统计只代表此次本机检查，不保证任意第三方节点都兼容。
- 图生任务仍需在手机选择参考图；电脑工作流中的任意本地文件路径不会自动传出。参考图选择不跨应用重启保留。
- 11 项工作流单元测试、6 项 Android 模拟器测试和 102 项后端测试通过。覆盖电脑参数保留、本地草稿隔离、完整工作流提交、丢失响应后的去重重试、点击缩略图获取原图、原图加载失败重试与缩放复位，以及原有画布和横竖屏功能。
- 修复同步目录误触发手机编辑路由的问题。模拟器使用可区分的缩略图和原图验证查看器确实加载原文件。
- 本次未触发真实 GPU 生成，未在实体手机验收。组件签名与目录合并只更新 ComfyUI，保留其他组件条目。
