# AI 对话 1.1.1

组件版本代码 4，moduleApi 2；最低主应用为 **工具匣 0.14.0 / versionCode 24**。搜索工具、设置弹窗和搜索 Key 加密存储全部内置于聊天组件，模型调用继续使用已有统一 AI 网关。

## 更新

在“组件管理”同步本仓库，再更新“AI 对话”。已有 0.14.0 或更新兼容宿主无需更新主应用，已安装 0.16.0 的设备也无需降级。直接覆盖更新会保留对话、记忆摘要及来源记录，请勿先卸载组件。本次发布不包含主 APK，其他 8 个组件条目保持不变。

## 智能搜索

- 打开聊天输入框下方“配置搜索”，选择 Tavily 或 DeepSeek，填写搜索 API Key 并保存，然后开启“智能搜索”。
- DeepSeek 搜索可使用与模型调用相同的官方 DeepSeek API Key，无需申请搜索专用 Key；需要在组件内手动填写，组件不读取主应用保存的模型凭据。第三方中转 Key 不能默认用于官方搜索接口。
- 默认地址为 `https://api.tavily.com/search` 或 `https://api.deepseek.com/v1/tools/search`。也可填写兼容服务的完整 HTTPS 搜索地址；更改服务或地址时需重新填写 Key。
- 短的首轮问题直接搜索；追问、长问题或多行问题先由当前模型结合历史整理为独立检索词，再搜索并流式回答。整理检索词会额外调用模型，可能产生模型费用。
- 每轮最多搜索一次、采用 5 条来源。Tavily 使用基础搜索，不自动升级；DeepSeek 使用搜索摘要。本版未加入网页全文 Fetch，不能视为已阅读全文。
- 回复提示使用 `[1]` 等编号；“搜索来源”展开真实工具返回的标题和可点击链接。来源会随会话保存，重开后仍可查看；实际来源链接不等于逐条陈述已完成事实核验。
- 搜索资料参与上下文预算，先缩短摘要、减少较低排名来源，再按需压缩较早对话；原始用户消息保持完整。
- 搜索失败、认证错误、额度不足、限流和空结果明确显示，不伪装为联网成功。停止可中断检索词整理、搜索和回答；取消与失败的轮次不进入后续上下文。手动重试会重新搜索，可能消耗额度。

搜索 Key 使用独立 Android Keystore 密钥加密后保存于组件私有目录，设置弹窗禁止截图，密钥不进入会话文件。卸载 AI 对话会删除会话和搜索配置。若曾使用本地试用版 1.1.0，需要在新组件里重新填写一次搜索 Key；旧宿主中的配置不会被读取或删除。

搜索和模型调用分别计费；[Tavily 额度说明](https://docs.tavily.com/documentation/api-credits)及 [DeepSeek 搜索文档](https://api-docs.deepseek.com/zh-cn/guides/search/)以服务商账户和当前规则为准。未添加自动充值或付费订阅。

## 保留的功能

输入 `/` 切换主应用当前来源的模型；多轮聊天、流式回复、停止、重试、本地历史、可编辑系统提示词和自动 / 手动上下文压缩继续可用。压缩保留本机原文，但摘要有损且会调用当前模型。

本版还没有深度思考开关、模型自主多次调用工具、网页全文抓取、附件或动态推荐追问。

## 验证

31 项 JVM 测试、15 项 Android API 34 设备测试通过。设备使用已交付的原版工具匣 0.14.0 APK（versionCode 24），没有重编译或替换宿主。覆盖两家搜索服务协议、界面配置、搜索 Key 加密存储及清除、来源恢复、追问改写、上下文裁剪、空结果、额度错误、重试和取消；还验证了从签名 chat 1.0.0 直接更新至 1.1.1 后会话 ID、消息和后续上下文保留。

测试使用本地 HTTP 模拟服务，没有调用用户的在线模型或搜索账户。真实 API 可达性、模型回答质量及其他厂商真机兼容性尚未实测。
