# MOSS 工作流支持：电脑连接服务 0.6.1

MOSS 保存工作流使用 ComfyUI 自带的 `SkipLayerGuidanceDiTSimple`。0.6.0 的电脑节点目录尚未包含它，导致工作流被列在「暂不能运行」。0.6.1 在检查本机 `comfy_extras.nodes_slg` 的实现与输入定义后补上该节点；不替换模型、不删除节点，也不改写电脑保存文件。

手机继续使用 ComfyUI **2.1.0**，本次没有修改或重新发布 Android 组件。在「电脑工作流」中同步目录，选择 MOSS 保存文件，修改提示词和尺寸后运行。跳层引导、模型、VAE、文本编码器、采样器及其他参数沿用所选工作流。

## 更新电脑

使用 [电脑连接服务 0.6.1](../desktop/comfy-bridge-0.6.1.zip)。停止旧连接服务，将包内 `services/`、`scripts/` 合并到原工具匣项目目录，保留 `.local-share/` 和 `.venv/`，然后重启。不要解压到 ComfyUI 安装目录。重启后手机用原口令重新登录，以启动日志中的当前地址为准。首次安装参见 [2.1.0 使用说明](comfy-2.1.0.md)。

## 验证

- 新增 5 项回归测试，覆盖保存文件转换、修改提示词/宽高、完整工作流提交、模型与引导参数保留、同名插件替换拒绝和参数范围检查。后端共 107 项通过。
- 本机两份 MOSS 保存工作流各 10 个节点，均通过转换与模型选项校验。
- 用当前手机端 `LocalWorkflow` 实现解析两份实际工作流，修改提示词与尺寸到 768×1024，再通过隔离的任务服务接收及电脑端重新校验。其余模型、引导和采样参数逐项一致，原文件未变。
- 手机端原有 11 项单元测试与新增的本地 MOSS 验证通过。本次无需重新构建手机组件；没有触发 GPU 生成，未在实体手机上完成生图验收。
- 发布包只包含电脑服务源码、启动脚本、示例方案、测试和说明；不包含本机 MOSS 工作流、用户提示词、模型、密钥或口令。
