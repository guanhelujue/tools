# AI 对话 1.1.3

组件版本代码 6，moduleApi 2；最低主应用为 **工具匣 0.14.0 / versionCode 24**。

## 更新

在“组件管理”同步本仓库，再更新“AI 对话”。直接覆盖更新保留原会话、模型选择、记忆摘要和搜索配置；请勿先卸载组件。无需更新主 APK，其他 8 个组件保持原版本。

## 系统提示词

本版将用户修改的提示词原样同步到组件内置文本。新对话使用新版；旧会话保留各自保存的提示词，需要切换时，在“对话设置”点击“使用内置提示词”并保存。

系统提示词最多为本地估算 4096 tokens。设置中显示长度，保存时为回复预留 2048 tokens，并额外保留至少 512 tokens 的问题空间和消息开销；预算不足时显示原因并禁用保存。可选择 4K / 8K / 16K 上下文预算，请根据提示词长度及模型能力选择。不会自动扩大服务商上下文限制。

## 原有功能

输入 `/` 切换主应用模型，流式回复、停止、重试、本地历史、自动 / 手动上下文压缩，以及组件内置 Tavily / DeepSeek 搜索和引用来源继续可用。搜索配置和 Key 加密存储仍位于组件内。搜索与模型调用可能分别产生服务商费用。

具体搜索配置与已有功能见 [1.1.1 使用说明](ai-chat-1.1.1.md)。本版不新增深度思考开关、网页全文抓取或动态推荐追问。

## 验证

打包通过 32 项 JVM 测试。自动校验确认编译后的 DEX 内置文本与用户文件一致，原提示词文件保持不变；未对提示词内容进行查看或改写。

发布前验证组件清单、发布签名、载荷 SHA-256、交付文件完整性及完整仓库目录合并。此前 1.1.2 已在原版 0.14.0 主应用上验证组件覆盖升级、提示词保存恢复、预算检查和聊天链路；1.1.3 本次未重新运行设备测试，也未调用真实在线模型。
